# Superpowers Engineering Skill Suite

This skill provides the core engineering disciplines from [obra/superpowers](https://github.com/obra/superpowers) for developing, testing, and maintaining high-reliability multi-agent systems.

## Available Sub-Skills in this Directory

| Skill | Path | Description |
| :--- | :--- | :--- |
| **Brainstorming** | [`./brainstorming/SKILL.md`](./brainstorming/SKILL.md) | Clarify real requirements and probe unknowns before writing specs or design docs. |
| **Writing Plans** | [`./writing-plans/SKILL.md`](./writing-plans/SKILL.md) | Break plans down into small, verifiable, bite-sized tasks. |
| **Executing Plans** | [`./executing-plans/SKILL.md`](./executing-plans/SKILL.md) | Execute plans in batches with checkpoints and validation. |
| **Test-Driven Development** | [`./test-driven-development/SKILL.md`](./test-driven-development/SKILL.md) | Write failing tests first, implement minimal code to pass, and refactor. |
| **Systematic Debugging** | [`./systematic-debugging/SKILL.md`](./systematic-debugging/SKILL.md) | Find root causes before fixing symptoms; test hypotheses methodically. |
| **Verification Before Completion** | [`./verification-before-completion/SKILL.md`](./verification-before-completion/SKILL.md) | Run real test suites and dry-runs to verify behavior before marking tasks done. |
| **Requesting Code Review** | [`./requesting-code-review/SKILL.md`](./requesting-code-review/SKILL.md) | Dispatch code reviews to independent agents or human reviewers. |
| **Subagent-Driven Development** | [`./subagent-driven-development/SKILL.md`](./subagent-driven-development/SKILL.md) | Parallelize and orchestrate work across specialized worker agents. |
